Descomprimir el ZIP del código y abrir la carpeta con pom.xml.
Iniciar MySQL de XAMPP y ejecutar database/schema.sql antes del primer arranque.
Ejecutar mvn spring-boot:run y abrir http://localhost:8080/.
Pruebas automáticas: mvn clean test. Java 17. H2 solo para pruebas.
Se reutiliza ockly_db; no es necesario borrar las tablas existentes.

y comprobación adicional del reinicio. Los datos anteriores se conservaron.
